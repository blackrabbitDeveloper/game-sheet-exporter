시트 구조

첫 세 행이 스키마입니다. 행 번호는 설정에서 바꿀 수 있고, 주석 행은 없어도 됩니다.

타입 표기

int long float double
숫자. 범위를 넘으면 오류
bool
TRUE true 1 Y O ↔ FALSE false 0 N X
string
문자열. 앞뒤 공백은 제거
datetime
엑셀 날짜 셀 또는 2026-07-30
loc
로컬라이즈 키. 셀에는 번역문이 아니라 키만
enum:Grade
enum.Grade 시트에 정의된 멤버 이름
ref:Item.id
Item 시트 id 열에 그 값이 있어야 함
int?
빈 셀 허용
int[]
배열. 셀 안에서 2001,2002 처럼 구분

int[]? 는 배열 전체가 없을 수 있고 int?[] 는 원소가 없을 수 있습니다. 순서를 뒤집으면 다른 타입입니다.

이름에 공백이 있으면 인용합니다 — ref:'몬스터 정보'.'고유 ID'

규칙

  • 첫 번째 열이 기본키입니다. 값이 유일하고 비어 있지 않아야 합니다.
  • 시트명이 enum. 으로 시작하면 enum 정의 시트입니다.
  • 시트명이 # 나 _ 로 시작하면 통째로 무시합니다. 필드명이 # 로 시작하면 그 열을 무시합니다.
  • 빈 셀에 기본값을 채우지 않습니다. 비워도 되는 열에는 ? 를 붙이십시오.
  • 대소문자를 구분합니다. Int 는 오류입니다.
  • 한글 시트명·필드명을 그대로 씁니다. C# 식별자로 변환된 이름을 함께 보여드립니다.
